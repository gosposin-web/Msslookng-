# Панель сторис

Мобильная панель для подключения своих Telegram-аккаунтов через код подтверждения и 2FA. При подключении можно выбрать собственный SOCKS5 или HTTP CONNECT прокси. Раздел просмотра сторис использует тестовые данные.

## Структура

- `backend/` содержит API на FastAPI и Telegram-клиент.
- `dist/` содержит интерфейс.
- `worker/` содержит шлюз для закрытой панели и сборку её интерфейса.

## Запуск API

```sh
python -m pip install -r backend/requirements.txt
python -m uvicorn --app-dir backend app:app --host 0.0.0.0 --port 8000
```

Переменные окружения перечислены в `backend/.env.example`. Ключи Telegram, токены сервиса и ключ шифрования задаются в настройках окружения. Запрос к `/healthz` проверяет запуск сервера.
